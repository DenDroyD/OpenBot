## Деплой на Bothost (aiogram 3 + Exchange EWS)

Этот проект — Telegram‑бот, который работает с Outlook/Exchange через EWS и поддерживает **много пользователей**:

- **Регистрация**: подтверждение номера телефона через Telegram Contact → сверка с Excel → ввод логина/пароля EWS → проверка подключения → сохранение.
- **Контакты**: Excel используется как база сотрудников для подстановки e‑mail участников.
- **Секреты**: токен бота и ключ шифрования **не лежат в коде**, задаются через Env.

### 0) Важно про GitHub: публичный или приватный?

- **Публичный репозиторий**: проще всего (Bothost сможет подтянуть без доступа).
- **Приватный репозиторий**: можно, но зависит от того, как вы будете деплоить:
  - либо Bothost должен уметь подключаться к приватному GitHub (token / deploy key),
  - либо вы загружаете ZIP проекта в панель Bothost.

⚠️ **Excel со списком сотрудников** содержит персональные данные — **не кладите его в публичный GitHub**.
Лучший вариант:
- репозиторий можно оставить публичным, но Excel загружать отдельно в Bothost в папку `data/`
- или делайте приватный репозиторий.

### 1) Какие файлы нужны

Минимум:
- `main.py` — бот
- `ews_api.py` — работа с EWS
- `employees.py` — чтение Excel и поиск сотрудников
- `app_storage.py` — SQLite + шифрование паролей
- `bot_utils.py` — даты/форматирование
- `requirements.txt`

Excel:
- `data/Список сотрудников.xlsx` (путь задаётся через `EMPLOYEES_XLSX_PATH`)

### 2) Env‑переменные в Bothost

Откройте в Bothost настройки Env и добавьте:

- `BOT_TOKEN` — токен Telegram бота
- `EWS_URL` — `https://mail.ecleasing.ru/ews/exchange.asmx`
- `DATA_ENCRYPTION_KEY` — ключ шифрования (Fernet)
- `EMPLOYEES_XLSX_PATH` — `data/Список сотрудников.xlsx`
- (если нужно) `EMP_COL_FIO`, `EMP_COL_PHONE`, `EMP_COL_EMAIL`

#### Как сгенерировать `DATA_ENCRYPTION_KEY`

Локально выполните:

```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

Скопируйте вывод и вставьте как значение `DATA_ENCRYPTION_KEY`.

### 3) Куда положить Excel

В Bothost загрузите файл в папку проекта:

`data/Список сотрудников.xlsx`

Если папки `data/` нет — создайте её.

### 4) Команда запуска

В Bothost укажите команду запуска:

```bash
python main.py
```

### 5) Как проходит регистрация пользователя

1) Пользователь пишет `/start`  
2) Бот показывает кнопку **«📱 Подтвердить номер телефона»** (Telegram отправляет Contact)  
3) Бот сверяет номер с Excel  
4) Бот просит логин `a.leonov` и пароль (EWS)  
5) Бот проверяет вход (пробует запросить встречи на сегодня)  
6) Сохраняет данные в `app.db` (пароль — **в шифрованном виде**)  

### 6) Что можно улучшить в рамках вашего тарифа Bothost

С учётом наличия Env‑переменных, диска и 1GB RAM:

- **Webhook вместо polling** (если Bothost даёт публичный HTTPS URL) — устойчивее и экономнее.
- **Redis‑FSM** (если Bothost даёт Redis) — чтобы состояния диалогов не терялись при рестарте.
- **Ограничения/защита**:
  - лимит попыток регистрации (anti‑bruteforce),
  - логирование ошибок EWS,
  - раздельные роли (админ/пользователь).
- **Улучшить поиск коллег**:
  - показывать варианты совпадений (когда score низкий),
  - предлагать выбрать из 3–5 вариантов кнопками.

### 7) Нюансы безопасности

- Пользователь вводит пароль в Telegram сообщением — это не идеально. Лучше:
  - завести отдельную служебную учётку и делегировать права,
  - или перейти на Microsoft Graph OAuth (тогда не нужно вводить пароль).
